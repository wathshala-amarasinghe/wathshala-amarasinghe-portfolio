## Overview

TrackMySavings is a personal finance tracking application designed to help users manage their income, expenses, and savings goals with clarity and ease.

## Challenge

The challenge was to design an interface that makes complex financial data instantly understandable, while keeping the experience clean and stress-free for everyday users.

## Approach

I conducted user research to understand how people track finances and identified common pain points with existing tools. This informed a focused, card-based UI with intuitive dashboards, clear data visualisations, and a minimal cognitive load design.

## Outcome

A high-fidelity, fully responsive UI built with React.js, TypeScript, Tailwind CSS, and Vite — with WCAG-accessible colour contrasts, interactive charts, and a streamlined user flow for adding and reviewing transactions.
