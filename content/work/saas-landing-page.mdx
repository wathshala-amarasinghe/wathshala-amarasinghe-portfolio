## Overview

A property listing web application designed to help students find nearby boarding places and hostel rooms around their campus.

## Technologies

HTML, CSS, JavaScript, PHP, MySQL, XAMPP

## Features

- Property listing and search with filters (location, price, room type)
- User registration and login for students and landlords
- Booking requests with dynamic database connectivity
- Search with real-time results from MySQL database
- Responsive design for mobile and desktop

## Outcome

A fully functional accommodation search platform that simplifies the process of finding student housing, with secure user authentication and dynamic, database-driven property listings.
