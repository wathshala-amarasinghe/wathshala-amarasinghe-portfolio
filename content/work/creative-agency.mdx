## Overview

A fully automated event management web application developed as my final year individual project — enabling event creators to book venues, assign tasks, and manage participants end-to-end.

## Technologies

HTML, CSS, JavaScript, PHP, MySQL, XAMPP, phpMyAdmin

## Features

- Responsive event creation and management system
- Role-based access control for Admins, Band Owners, and Event Managers
- Dynamic participant registration with email notifications
- Venue availability calendar and booking management
- Integrated task assignment and progress tracking

## Outcome

A fully functional, database-driven event management platform with a secure MySQL backend managed via phpMyAdmin. Focused on improving user experience, automating repetitive workflows, and delivering a reliable system under real-world conditions.
