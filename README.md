# Wathshala Amarasinghe Portfolio

Production portfolio for Wathshala Amarasinghe, a UI/UX Product Designer and Engineer based in Sri Lanka. The site presents three public projects—KAVON, Smart Web POS and Nation Spice—alongside experience, services, tools, testimonials and a server-side contact form.

Production URL: <https://wathshalaamarasinghe.com>

## Technology

- Next.js 16 App Router and React 19
- TypeScript and Tailwind CSS 4
- GSAP for focused reveal interactions
- Nodemailer with Gmail SMTP for the contact endpoint
- Playwright and axe-core for browser and accessibility checks

## Local setup

Use Node.js 20.9 or newer. This project is currently verified with Node.js 24 and npm 11.

```powershell
npm ci
Copy-Item .env.example .env.local
npm run dev
```

Open <http://localhost:3000>. Add real email credentials to `.env.local`; never commit that file.

Required environment variables:

```env
GMAIL_USER=your-gmail-address@example.com
GMAIL_APP_PASSWORD=your-google-app-password
```

`CONTACT_TO_ADDRESS` is optional. When omitted, the endpoint uses the portfolio owner’s server-controlled address.

## Commands

```powershell
npm run dev        # Development server
npm run format     # Format supported project files
npm run typecheck  # TypeScript validation
npm run lint       # ESLint validation
npm run test       # Desktop and mobile Playwright checks
npm run build      # Production build
npm run start      # Start the production build
```

## Project structure

- `src/app` — pages, metadata routes and the contact API
- `src/components` — layout, sections, project case studies and controls
- `src/data` — portfolio content and case-study copy
- `src/styles` — theme and motion tokens
- `public` — images, video, documents and technology icons
- `tests/e2e` — functional, SEO, contact and accessibility checks
- `docs` — detailed setup and asset inventory

## Production behavior

- Canonical metadata targets `https://wathshalaamarasinghe.com`.
- `/robots.txt`, `/sitemap.xml` and `/opengraph-image` are generated by Next.js.
- Security headers are configured in `next.config.ts`.
- The decorative background video is homepage-only, starts after desktop interaction settles (or a ten-second idle fallback), and is not requested on mobile, reduced-motion or data-saving connections.
- The preloader is non-interactive, short-lived and limited to slow first loads in a browser session.
